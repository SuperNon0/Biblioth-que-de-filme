première configuration

Bienvenue ! 🎬 Pour fonctionner, cinéthèque a besoin d'une clé API TMDB — c'est ce qui remplit automatiquement les fiches (affiches, résumés, durées, épisodes, sorties…). Elle est gratuite et sans limite de durée pour un usage personnel.

Créer ta clé (2 minutes)

  1. Crée un compte gratuit sur themoviedb.org.
  2. Va sur themoviedb.org/settings/api (Paramètres → API).
  3. Demande une clé « Developer » (usage personnel), accepte les conditions.
  4. Copie la « API Key (v3 auth) » et colle-la ci-dessous.
Configurer plus tard (accès limité sans clé)
