Aide & support

      
Tout ce qu'il faut pour installer, sécuriser et
        utiliser cinéthèque. Les liens t'emmènent directement au bon onglet.


      

        
🚀 Premiers pas

        

          

            
🔑

            
Clé API TMDB

            
Gratuite et sans limite, elle remplit automatiquement les fiches
              (affiches, résumés, épisodes, sorties).

            
    
              
  1. Compte sur themoviedb.org
    2. 
              
  2. Paramètres → API
    3. 
              
  3. Copie la clé « API Key (v3 auth) »
    4. 
            

            
Colle-la dans Paramètres → Clé TMDB.

          

        

      


      

        
🔐 Compte & sécurité

        

          

            
🔒

            
Mot de passe

            
Compte unique admin. Change-le dans
              Paramètres → Mot de passe.

            
Oublié ? Depuis le serveur (console Proxmox / SSH) :

            
sudo bash /opt/cinetheque/scripts/reset-admin-password.sh

          

          

            
🌐

            
Connexion automatique

            
Derrière Cloudflare Access, tu es connecté automatiquement.
              En accès par l'IP locale, le mot de passe reste exigé.

            
Réglable dans
              Paramètres → Connexion automatique.

          

        

      


      

        
💾 Tes données

        

          

            
💾

            
Sauvegarde & export

            
Exporte ou restaure tes données depuis
              Paramètres → Sauvegarde.

            
Archive complète (avec affiches) depuis le serveur :

            
sudo bash /opt/cinetheque/scripts/backup.sh

          

          

            
⬆️

            
Mettre à jour le site

            
Récupère la dernière version depuis GitHub sans toucher à tes données.

            
sudo /opt/cinetheque/scripts/update-panel.sh

🔔 Configurer les notifications Discord (botpanel)

        

          
cinéthèque envoie ses notifications via botpanel (aucun réglage
            Discord ici). À faire une seule fois :

          
    
            
  1. Dans botpanel, crée 3 notifications avec des
              emplacements {var:nom} (modèles ci-dessous) et note
              le slug de chacune.
    2. 
            
  2. Dans cinéthèque → Paramètres →
              Notifications, coche Discord, mets l'URL de botpanel
              et reporte les 3 slugs, puis « Tester l'envoi ».
    3. 
          

          
💡 Le slug se choisit dans botpanel à la
            création de la notif, et se renseigne (le même) dans les
            Paramètres de cinéthèque. Modifiable des deux côtés tant qu'il reste
            identique.


          

            
📺 Nouvel épisode d'une série

            
Titre📺 {var:serie}

            
MessageNouvel épisode {var:code} — {var:titre|à regarder} 🍿

            
Variables : serie, code, titre, saison, episode

          


          

            
🎬 Film au cinéma

            
Titre🎬 {var:titre}

            
MessageC'est sorti — maintenant au {var:canal} ! 🎟️

            
Variables : titre, canal

          


          

            
📺 Film disponible en streaming

            
Titre📺 {var:titre}

            
MessageDisponible en streaming sur {var:plateformes|une plateforme} 🎬

            
Variables : titre, plateformes

          


          
La syntaxe {var:nom|défaut} affiche
            « défaut » si la variable est absente.

          
🖼️ Images sur Discord : dans le template botpanel,
            mets {var:affiche} dans « Large Image (URL) » pour
            le grand poster, et {var:logo} dans « Thumbnail »
            pour le logo cinéthèque en coin. Variable {var:image}
            aussi dispo (vignette de l'épisode pour les séries).
