Aide & support

Toutes les informations utiles pour gérer ta cinéthèque.

🔑 Clé API TMDB — créer, gérer, modifier

cinéthèque utilise l'API TMDB pour remplir les fiches (affiches, résumés, durées, épisodes, sorties). Elle est gratuite et sans limite de durée pour un usage personnel.

Créer la clé :

  1. Compte gratuit sur themoviedb.org.
  2. Aller sur themoviedb.org/settings/api (Paramètres → API).
  3. Demander une clé « Developer » (usage personnel), accepter les conditions.
  4. Copier la « API Key (v3 auth) ».

Renseigner / modifier : onglet Paramètres → Clé API TMDB, colle la clé, choisis la région (FR), puis « Enregistrer » et « Tester ». La clé est stockée dans le fichier settings.json du serveur.

🔒 Mot de passe — changer, oublier, réinitialiser

Compte unique admin (pas d'identifiant, juste un mot de passe).

Le changer : onglet Paramètres → Mot de passe (8 caractères minimum).

Oublié ? Depuis le serveur (console Proxmox ou SSH) :

sudo bash /opt/cinetheque/scripts/reset-admin-password.sh

Secours ultime (remet le mot de passe défini à l'installation) :

sudo rm /opt/cinetheque/data/users.json
sudo systemctl restart cinetheque-panel
🌐 Connexion automatique (Cloudflare Access)

Derrière Cloudflare Access (login Google), tu es connecté automatiquement. En accès direct par l'IP locale, le mot de passe reste exigé.

Active/désactive cette protection et restreins à ton email dans Paramètres → Connexion automatique.

💾 Sauvegarde, export et restauration

Depuis le site : Paramètres → Sauvegarde — « Exporter » télécharge toutes tes données en un fichier JSON, « Importer » les restaure.

Depuis le serveur (archive complète, incluant les affiches) :

sudo bash /opt/cinetheque/scripts/backup.sh
sudo bash /opt/cinetheque/scripts/restore.sh cinetheque-AAAAMMJJ-HHMMSS.tar.gz
⬆️ Mettre à jour le site

Depuis le serveur :

sudo /opt/cinetheque/scripts/update-panel.sh

Récupère la dernière version depuis GitHub et redémarre le site sans toucher à tes données.

📚 Comment utiliser cinéthèque
  • Ajouter : tape un nom dans la recherche en haut → clique le résultat. (Titre absent ? Ajout manuel.)
  • Séries : ouvre la fiche → déplie une saison → coche chaque épisode « Vu » (ou « Tout marquer »).
  • Statuts : Vu, À voir, En cours, Abandonné (sur chaque fiche).
  • Listes : « À voir » et « Favoris » existent par défaut ; crée les tiennes ou importe une liste toute prête.
  • Statistiques : onglet Profil (temps total, compteurs, genres, temps par série).
