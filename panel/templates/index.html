Aide & support

Tout ce qu'il faut pour installer, sécuriser et utiliser cinéthèque. Les liens t'emmènent directement au bon onglet.

🚀 Premiers pas

🔑

Clé API TMDB

Gratuite et sans limite, elle remplit automatiquement les fiches (affiches, résumés, épisodes, sorties).

  1. Compte sur themoviedb.org
  2. Paramètres → API
  3. Copie la clé « API Key (v3 auth) »

Colle-la dans Paramètres → Clé TMDB.

🔐 Compte & sécurité

🔒

Mot de passe

Compte unique admin. Change-le dans Paramètres → Mot de passe.

Oublié ? Depuis le serveur (console Proxmox / SSH) :

sudo bash /opt/cinetheque/scripts/reset-admin-password.sh
🌐

Connexion automatique

Derrière Cloudflare Access, tu es connecté automatiquement. En accès par l'IP locale, le mot de passe reste exigé.

Réglable dans Paramètres → Connexion automatique.

💾 Tes données

💾

Sauvegarde & export

Exporte ou restaure tes données depuis Paramètres → Sauvegarde.

Archive complète (avec affiches) depuis le serveur :

sudo bash /opt/cinetheque/scripts/backup.sh
⬆️

Mettre à jour le site

Récupère la dernière version depuis GitHub sans toucher à tes données.

sudo /opt/cinetheque/scripts/update-panel.sh

🎬 Bien utiliser cinéthèque

➕

Ajouter un titre

Tape un nom dans la recherche en haut, puis clique le résultat. Absent de TMDB ? Ajout manuel.

📺

Suivre une série

Ouvre la fiche, déplie une saison, coche chaque épisode « Vu » — ou « Tout marquer » d'un coup.

📃

Listes & découverte

« À voir » et « Favoris » par défaut, listes toutes prêtes (Marvel, Star Wars…), et la roulette « Que regarder ? ».

🔔

Notifications

Sois prévenu des nouveaux épisodes et sorties (Discord / ntfy) via Paramètres → Notifications.

📊

Statistiques

Temps total, compteurs, genres et temps par série dans Profil.

🔔 Configurer les notifications Discord (botpanel)

cinéthèque envoie ses notifications via botpanel (aucun réglage Discord ici). À faire une seule fois :

  1. Dans botpanel, crée 3 notifications avec des emplacements {var:nom} (modèles ci-dessous) et note le slug de chacune.
  2. Dans cinéthèque → Paramètres → Notifications, coche Discord, mets l'URL de botpanel et reporte les 3 slugs, puis « Tester l'envoi ».

💡 Le slug se choisit dans botpanel à la création de la notif, et se renseigne (le même) dans les Paramètres de cinéthèque. Modifiable des deux côtés tant qu'il reste identique.

📺 Nouvel épisode d'une série
Titre📺 {var:serie}
MessageNouvel épisode {var:code}{var:titre| }
Variables : serie, code, titre, saison, episode
🎬 Film au cinéma
Titre🎬 {var:titre}
MessageMaintenant au {var:canal} !
Variables : titre, canal
📺 Film disponible en streaming
Titre📺 {var:titre}
MessageDisponible sur {var:plateformes|une plateforme}.
Variables : titre, plateformes

La syntaxe {var:nom|défaut} affiche « défaut » si la variable est absente. ntfy (autre canal, réglé dans cinéthèque) reçoit déjà le texte complet, sans configuration.
