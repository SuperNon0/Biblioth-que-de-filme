Premiers pas

          
Comment obtenir la clé TMDB ?
            
Elle est gratuite et sans limite de durée. Elle remplit les fiches : affiches, résumés, épisodes, sorties.

              
  1. Crée un compte sur themoviedb.org.
    2. 
                
  2. Va dans Paramètres → API et demande une clé « Developer ».
    3. 
                
  3. Copie la clé « API Key (v3 auth) ».
    4. 
                
  4. Colle-la dans Paramètres → Clé TMDB.

          
Comment ajouter un film ou une série ?
            
Touche la loupe (ou Ctrl K sur ordinateur), tape le nom, puis choisis le titre. Sur sa fiche : « À voir plus tard » ou « Vu ».

              
Depuis n'importe quelle affiche, le menu rapide fait la même chose sans ouvrir la fiche.

          
Un titre est absent de TMDB : comment l'ajouter ?
            
Dans la Bibliothèque, le bouton + ouvre l'ajout manuel : titre, film ou série, année, durée et résumé.


          
Suivre tes séries

          
Comment marquer un épisode vu ?
            
Le plus rapide : touche l'affiche de la série, puis le gros bouton « Marquer S1 · É5 vu ». Le menu reste ouvert sur l'épisode suivant, pour enchaîner.

              
Dans la fiche, onglet Épisodes : coche le rond à droite de l'épisode. Toucher un épisode déjà vu retire un visionnage.

          
Comment marquer une saison entière, ou tout jusqu'à un épisode ?
            
Ouvre la saison dans la fiche : le bouton « Marquer la saison vue » coche tous ses épisodes déjà diffusés.

              
Pour tout cocher jusqu'à un épisode, appuie longtemps dessus (ou passe par son menu ⋯) : « Marquer jusqu'à É8 » annonce le nombre d'épisodes et leur durée avant de valider.

              
Les épisodes pas encore diffusés sont rangés à part et ne comptent pas.

          
J'ai revu un film, un épisode ou une série
            
Film : sur sa fiche, « J'ai revu » ajoute un visionnage daté du jour. Épisode : son menu ⋯ propose « Je l'ai revu ». Saison ou série entière : les boutons « J'ai revu » de l'onglet Épisodes.

              
Chaque revisionnage compte dans le temps total du Profil.

          
Je me suis trompé : comment annuler ?
            
Après chaque marquage, un message « Annuler » reste 5 secondes en bas de l'écran : touche-le pour tout remettre comme avant.

              
Plus tard : retire le visionnage depuis la fiche (la croix à côté de la date pour un film, le rond de l'épisode pour une série).

          
Que veut dire « S1 · É5 · 4 / 30 » sous une affiche ?
            
« S1 · É5 » est le prochain épisode à voir (saison 1, épisode 5). « 4 / 30 » : 4 épisodes vus sur les 30 déjà diffusés. Les épisodes à venir ne comptent pas.

              
La coche verte veut dire vu, le marque-page « à voir plus tard », la barre violette la progression d'une série.


          
Listes et découverte

          
Comment ajouter un titre à une liste ?
            
Menu rapide ou fiche → « Liste » : coche une ou plusieurs listes. « Nouvelle liste » se crée directement dans la même feuille.

              
Dans la Bibliothèque, un appui long sur une affiche (ou « Choisir ») sélectionne plusieurs titres d'un coup.

          
À quoi servent les listes « dans l'ordre » ?
            
Pour une saga (Marvel, Star Wars…) : chaque titre porte son numéro et le prochain à voir est mis en avant. Fais glisser la poignée pour changer l'ordre. Les listes prêtes sont déjà dans l'ordre.

          
Comment ne voir que ce qui est sur mes plateformes ?
            
Indique tes abonnements dans Paramètres → Mes plateformes. Ensuite, l'interrupteur « Sur mes plateformes » de Découvrir ne garde que ce qui est inclus, et un petit logo apparaît sur les affiches.

          
Comment être prévenu d'une sortie au cinéma ?
            
Dans Futur, touche la cloche d'un film : tu seras prévenu sur Discord le jour de sa sortie. Un second toucher retire l'alerte.

          
Je ne sais pas quoi regarder
            
« Que regarder ? » dans la Bibliothèque pioche au hasard dans ta liste « À voir plus tard ». « Au hasard » dans Découvrir pioche dans tout le catalogue.


          
Raccourcis sur ordinateur

          
Quels raccourcis clavier existent ?
            
  • Ctrl K ou / : rechercher partout.
    • 
              
  • Sur une affiche survolée : V vu, A à voir, L liste, Entrée fiche.
    • 
              
  • Clic droit ou ⋯ sur une affiche : le menu des actions.
    • 
              
  • Échap : fermer la fiche ou le menu ouvert.


          
Compte et sécurité

          
J'ai oublié mon mot de passe
            
Depuis le serveur (console Proxmox ou SSH), lance cette commande puis choisis un nouveau mot de passe :

              
sudo bash /opt/cinetheque/scripts/reset-admin-password.sh

          
Pourquoi je n'ai pas besoin de mot de passe ?
            
Derrière Cloudflare Access, ton e-mail est déjà vérifié : tu es connecté automatiquement. Par l'adresse IP locale, le mot de passe reste demandé.{% if is_super_admin %} Réglable dans Paramètres → Cloudflare Access.{% endif %}


          
Tes données

          
Comment sauvegarder mes données ?
            
{% if is_super_admin %}Paramètres → Sauvegarde télécharge un fichier avec toute ta bibliothèque. {% endif %}Archive complète, avec les affiches, depuis le serveur :

              
sudo bash /opt/cinetheque/scripts/backup.sh

          
Comment mettre à jour le site ?
            
{% if can('site_update') %}Paramètres → Version et mise à jour : un bouton, sans toucher à tes données. {% endif %}Depuis le serveur :

              
sudo /opt/cinetheque/scripts/update-panel.sh

          
Comment est calculé le temps total ?
            
films vus × leur durée
+ épisodes vus × leur durée
(chaque revisionnage compte)

              
Un épisode sans durée connue compte pour 45 minutes.


          
Notifications Discord (botpanel)

          
Comment configurer les notifications Discord ?
            

              
cinéthèque envoie ses notifications par botpanel. À faire une seule fois :

              
  1. Dans botpanel, crée 3 notifications avec les modèles ci-dessous, et note le slug de chacune.
    2. 
                
  2. Dans {% if is_super_admin %}Paramètres → Discord{% else %}Paramètres → Discord{% endif %}, active l'envoi, indique l'adresse de botpanel et les 3 slugs, puis « Envoyer un test ».

              
Le slug se choisit dans botpanel à la création de la notification, et se recopie à l'identique dans cinéthèque.
